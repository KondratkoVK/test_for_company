# test_for_company
# Тестовая HTML/CSS вёрстка

Данный проект представляет собой простую веб-страницу, выполненную в рамках тестового задания.

## Описание
Сайт сверстан с использованием чистых **HTML** и **CSS** без применения JavaScript и сторонних библиотек. Основная цель проекта — продемонстрировать базовые навыки вёрстки, работу с семантической разметкой и стилизацией страницы.

## Особенности
- Чистая HTML/CSS вёрстка без использования JavaScript
- Использование семантических тегов
- Простая и понятная структура страницы
- Стилизация элементов с помощью CSS
- Аккуратный и минималистичный дизайн

## Цель проекта
Проект был создан в качестве **тестового задания** для демонстрации базовых навыков разработки интерфейсов и работы с HTML и CSS.
